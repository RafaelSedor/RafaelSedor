## Como eu trabalho

- **Produto antes do código:** levantamento de requisitos com o cliente, épicos, priorização MoSCoW e histórias de usuário
- **Validação na borda e erros centralizados:** input validado antes da regra de negócio, respostas de erro consistentes
- **Qualidade automatizada:** testes unitários, de integração e E2E (Playwright), CI/CD com GitHub Actions em tudo que entrego
- **Infra como parte do produto:** Docker, ambientes de produção, monitoramento e otimização guiada por métricas
